Каталог элементов навигации ГКБ №7 — версия для своего хостинга

Состав папки:
  index.html — страница каталога (открывается и просто двойным щелчком, без сервера)
  data.js    — данные: указатели, типы, характеристики, кабинеты
  img/       — миниатюры дизайна и чертежи типов

Как выложить:
  Загрузите всю папку целиком на любой хостинг статических сайтов
  (свой сервер, Netlify, Cloudflare Pages, GitHub Pages).
  Адрес страницы — адрес папки, например https://ваш-домен/gkb7-navigation/

Доступ:
  Страница помечена «noindex», поисковики её не индексируют, но по прямой
  ссылке она открыта всем. Чтобы закрыть её паролем, включите защиту
  паролем в настройках хостинга.

Шрифты Inter и IBM Plex Mono подгружаются с Google Fonts; без интернета
страница работает со стандартным системным шрифтом.
