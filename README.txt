Каталог элементов навигации ГКБ №7 — статическая версия для GitHub Pages
========================================================================

СОСТАВ
  index.html   — сама страница (всё оформление и логика внутри)
  data.js      — данные каталога (элементы, типы, ссылки)
  config.js    — настройка синхронизации выгрузок (см. ниже)
  img1…img4    — изображения: эскизы элементов и страницы спецификации
                 (разбиты по 100 файлов, чтобы загружать в репозиторий порциями)

КАК ОПУБЛИКОВАТЬ
  1. Создайте репозиторий на GitHub.
  2. Загрузите файлы, сохраняя структуру папок: index.html, data.js, config.js
     в корень, затем по очереди папки img1, img2, img3, img4
     (Add file → Upload files, не более 100 файлов за раз).
  3. Settings → Pages → Source: Deploy from a branch → branch main, папка / (root).
  4. Через 1–2 минуты страница откроется по адресу
     https://<логин>.github.io/<репозиторий>/

ЖУРНАЛ И СИНХРОНИЗАЦИЯ (config.js)
  Страница сообщает в веб-приложение Google Apps Script (адрес в config.js, поле url)
  о двух событиях: вход на страницу (время, логин, браузер) и выгрузка списка для КП
  (время, логин, имя файла и сам список). В таблице это два листа — «Входы»
  и «Выгрузки». Оттуда задача по расписанию складывает выгрузки файлами .xlsx
  в папку «Выгрузки КП» и дописывает «Журнал входов.csv».
  Чтобы отключить — оставьте url пустым. Ключ key должен совпадать с ключом в скрипте.

ВХОД НА СТРАНИЦУ
  Каталог закрыт логином и паролем. Данные (data.js) зашифрованы этой парой,
  поэтому без неё страница не показывает ничего. Пара выдана отдельно —
  см. файл «доступ-к-странице.txt» в папке «Проект навигации ГКБ 7»;
  в репозиторий она не попадает. Пароль запоминается до закрытия вкладки.
  Важно: файлы эскизов в папках img1…img4 шифрованием не закрыты и доступны
  по прямым адресам — защита рассчитана на случайного посетителя, не на взлом.
  Смена пароля — пересборка архива.

ЗАМЕЧАНИЯ
  • Страница не требует сервера: её можно открыть и локально, двойным щелчком.
  • Шрифты подгружаются с Google Fonts; без интернета подставятся системные.
  • Страница закрыта от индексации поисковиками (meta robots: noindex).
